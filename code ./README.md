# 🚀 Smart Workforce & Analytics API

A modern, high-performance REST API built with FastAPI designed for next-generation employment management. This system goes beyond traditional HR tools by providing an infrastructure for real-time attendance tracking, automated productivity logging, and intelligent workforce analytics.

## ✨ Features
* **Core HR Management:** Comprehensive endpoints for employee onboarding, role assignment, and profile management.
* **Smart Attendance Integration:** Endpoints designed to ingest and query logs from smart-gate systems.
* **Workplace Analytics:** Data aggregation for employee activity, focusing on wellness, focus metrics, and fatigue tracking.
* **Modern Stack:** Built entirely on Python, FastAPI, and SQLAlchemy with Pydantic for rigorous data validation.
* **Interactive Documentation:** Out-of-the-box Swagger UI integration for easy endpoint testing.

## 🛠️ Tech Stack
* **Framework:** FastAPI
* **Database Management:** SQLAlchemy (ORM)
* **Data Validation:** Pydantic
* **Server:** Uvicorn

## 📂 Project Architecture
The project strictly follows a layered architecture pattern, separating routing (`api/routes`), business logic (`services/`), database interaction (`models/`), and data validation (`schemas/`) to ensure enterprise-level scalability and clean code separation.
